# Buffer Commit submission draft

**Project:** BuildLog

**Tagline:** Turn real GitHub progress into a post you can review.

**Overview:** Builders ship meaningful work, but turning that work into an accurate public update takes extra effort. BuildLog lets a user sign in with GitHub, select a commit or merged pull request from a public repository, choose and edit a starting draft, and queue the reviewed post through their own Buffer account. The source change stays visible, and the app warns that a commit or merge does not mean released or live.

**Who it helps:** Independent builders, open-source maintainers, and small teams sharing their progress.

**Buffer integration:** Users connect their own Buffer account with OAuth, select an available channel, and approve a post for the queue. Queueing is distinct from publishing.

**Current limits:** Draft options are templates based on pull request titles or commit messages. It does not inspect diffs or independently verify claims; the user must review and edit it. Public deployment and OAuth flow must be verified before submission.
